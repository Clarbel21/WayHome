# Interactive check-in demonstration

1. Open **Demo control center → Check-in interaction demo → Start feeling check-in**. On the wearable, choose **I'm okay**. It reassures and records the response/time under caregiver **Alerts → Check-in responses**. Existing device or safety concerns still prevent normal monitoring.
2. Start again → **I need help → Help me get home**. One approved landmark and instruction appear. **I see it** advances one step; **I don't see it** stops directions and offers family assistance. With low GPS confidence, guidance remains paused and explains the uncertainty.
3. Start again → **I need help → Contact my family**. Open caregiver **Alerts** in another tab. Choose **Acknowledge family request**, then **Simulate caregiver response**. The wearable updates at each stage. **Continue after response** returns to monitoring only when existing safety gates permit it.
4. Start again → **I need help → I'm confused**. A calm message, familiar approved photo, and family contact appear without recognition testing.
5. Select a 15/30/60-second timeout and notification policy in the demo or Settings. Start a check-in and wait twice, or press **Simulate response timeout** twice. The first repeats gently; the second logs an unresolved check-in. Notification is simulated only when enabled. The unanswered interaction cannot be cleared by the normal-walk simulator.
6. Hold **SOS** during any branch. It interrupts immediately; check-in answers, stale timers, and family responses cannot resolve the incident. Use the existing caregiver incident-resolution flow separately. Memory Garden progress and caregiver-reviewed device warnings remain preserved.

## Limits

Directions, caregiver notifications, responses, wear readings, and GPS confidence remain simulations. No real calls or emergency messages are sent. Timers run while the app is open and resume from saved deadlines when reopened; browser background throttling can delay prompts. State and history are local to this browser (shared across its tabs), with no remote caregiver service. The supplied familiar-place pictures remain demo illustrations; caregiver-approved uploaded photographs continue to work through the existing landmark library and separate navigation approval.
