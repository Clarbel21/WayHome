# Demonstrating the WayHome refinements

Use the existing Pages site after its deployment turns green. All observations and emergencies below are simulated. Two tabs on the same browser/origin show caregiver and wearer updates.

1. **Uncertain attachment (30 seconds).** In Caregiver Settings, choose Pendant. Status becomes Unknown. Record “lanyard fastened: yes” and “near-body proximity: no”: Possibly removed. Both yes: Likely worn, explicitly an inference. Repeat with the clip’s garment-motion input if desired. Visit Digital twin to see the attachment styling.
2. **Understandable scenarios (45 seconds).** In Demo Control Center, trigger route deviation and read its 100 m threshold explanation. Trigger low GPS confidence: deviation is no longer inferred and guidance pauses. Clear simulated readings, then Review check-in. Try prolonged inactivity and missed check-ins; explain that these request support, never automatic police dispatch. Clear/review again before a memory activity.
3. **Resolution is not acknowledgment (60 seconds).** Trigger wearable removal, disconnection, then SOS. In Emergency Assistance, acknowledge the event: S5 remains active. Request incident resolution and confirm the independent wearer check. Confirm that help was received: the incident closes, but the device warnings remain and local memories may continue after caregiver review. Neither connection nor wear changed. Restore the simulated connection: wear is still Unknown. Record likely-worn observations and clear any outstanding scenario readings. Review the check-in after those observations to clear remaining device-review status. Show preserved alert history. For SOS precedence, send another SOS from the wearer tab during pending verification: it returns to active and invalidates the pending confirmation. Full Reset Demo is blocked during unresolved S5.
4. **Optional memories (30 seconds).** Set preferred activity types/music notes in Memory Library. In Companion → Explore Memories, read the optional suggestion. Skip an activity: an alternative may be suggested, but the original remains available and garden progress is unchanged. Nothing starts automatically.
5. **Separate navigation approval (45 seconds).** Approve a place/photo for memories, then Propose for landmark guidance. Enter a distinct simple instruction. In Familiar landmarks it is pending and excluded from guidance. Review the copied photo and instruction, then separately approve navigation. It is now eligible for guidance. Deleting the original memory leaves the independent navigation copy intact; explain that memory and navigation approvals are intentionally separate.

No observation, acknowledgment, verification label or successful demo proves real-world safety. The thresholds and attachment sensors are illustrative; no real GPS tracking, wear detection or emergency messages occur.
